步驟 01. 終端業務調用發起 (User Prompt Ingress) 階段 01
業務端 Web Portal / MES 智慧產線 / 研發 IDE 插件發起 OpenAI 兼容推論請求。
/v1/chat/completions SSO JWT Token RAG Context
👉 對應右側：Tier 1 客戶端展示層
⬇️ TLS 1.3 雙向加密傳輸 ⬇️
步驟 02. 邊界安全與零信任鑑權 (Zero-Trust Perimeter) 階段 02
Envoy 閘道 mTLS 終結，Keycloak 檢驗 JWT 簽名與 RBAC 權限，WAF 深度清洗注入攻擊。
Envoy Gateway mTLS 終結 WAF Anti-Injection Rate Limiter
👉 對應右側：Tier 2 安全邊界入口閘道層
⬇️ 鑑權通過，進入內網專線 ⬇️
步驟 03. 語意向量快取比對 (Semantic Vector Cache) 階段 03
計算 Prompt Embedding，檢索 Redis Vector 餘弦相似度。若 Cosine > 0.95 判定為重複問答。
Redis Vector DB Cosine > 0.95 ⚡ 命中延遲 < 10ms $0 零算力
⚡ 命中分支：直接短路跳至步驟 08 回應用戶，跳過後續模型推論！
⬇️ 未命中快取，進入路由分析 ⬇️
步驟 04. 語意意圖分類與難度打分 (Lightweight Scorer) 階段 04
輕量 Fine-tuned BERT 分類器 (<15ms) 快速剖析意圖維度，計算複雜度評分 (0.0 ~ 1.0)。
FastBERT (<15ms) 閥值 Tau = 0.65 常規問答 vs 複雜推理
👉 對應右側：Tier 3 智慧模型路由中樞核心
⬇️ 輸出分流決策權重 ⬇️
步驟 05. 專利機密與 PII 動態脫敏 (Enterprise DLP) 階段 05
針對需調用雲端之請求，在本地動態遮蔽專利代碼、料號與個人資料，記憶體維護實體映射字典。
Microsoft Presidio 在地 NER 遮罩 Token 雜湊替換 零機密外洩
👉 確保傳出內網之資料 100% 脫敏，絕無機密洩露
⬇️ 派發至最佳推論軌道 ⬇️
步驟 06. 雙軌混合算力智能分發 (Dual-Track Dispatch) 階段 06
常規 70% 負載派發地端私有 vLLM；攻堅 30% 難題經專線派發至 AWS Bedrock / OpenRouter。
軌道 A: 70% 地端私有 軌道 B: 30% 雲端攻堅 軌道 C: OpenRouter 比價
👉 對應右側：Tier 4 雙軌混合算力推論引擎層
⬇️ 模型推論完成，回傳結果 ⬇️
步驟 07. 安全護欄檢測與實體逆向還原 (De-anonymize) 階段 07
Llama Guard 3 檢查輸出毒性與格式，藉由 Session 映射表將遮罩 Token 逆向還原為真實內容。
Llama Guard 3 逆向字典反遮罩 向量快取非同步預熱
👉 審核通過後，自動寫入 Redis 語意快取
⬇️ 流式推送至客戶端 ⬇️
步驟 08. 流式響應交付與 FinOps 遙測稽核 (SSE & FinOps) 階段 08
SSE 打字機流式交付終端，OpenTelemetry 記錄 TTFT 首字延遲，Kafka 異步結算部門預算。
SSE 打字機流 OpenTelemetry Kafka / ClickHouse 預算熔斷防護
