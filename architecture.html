🛡️ 防混淆代理 (Anti-Confused Deputy)

控制通道（系統指令）與資料通道（外部檢索內容）物理拆分，外部 RAG 輸入強制封裝於唯讀沙箱，禁止直接作為可執行指令直譯。

🔑 NHI 身分動態憑證

HashiCorp Vault ＋ SPIFFE/SPIRE 動態發放 X.509 SVID 憑證，強制有效期 < 15 分鐘，徹底根除 API Key 硬編碼外洩風險。

⚡ 高風險操作人機介入 (HITL) 四眼原則 SOP

單筆異動金額 > NT$50,000 或批次修改逾 100 筆時，系統自動熔斷掛起並向主管發送審核 Webhook，人工雙簽後方放行 MCP 代理執行。
